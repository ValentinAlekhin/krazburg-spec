# Задача и границы проекта

Покупатель без опыта монтажа должен определить подходящий комплект натяжного потолка, понять состав и предварительную стоимость, затем передать расчёт менеджеру.

## Первый этап

| Возможность | Принятое решение |
| --- | --- |
| Расчёт | Предварительный; перед изготовлением его проверяет менеджер |
| Помещения | Несколько комнат в одной заявке |
| Форма помещения | Замкнутый многоугольник с прямыми стенами, включая ниши и непрямые углы |
| Наглядность | 2D-схема помещения |
| Сохранение | Автоматически в этом браузере, без регистрации |
| Работа с покупателем | Заявка в админке Strapi и уведомление по email |
| Управление | Каталог, цены, комплекты, совместимость и предусмотренные параметры расчёта |

## За пределами первого этапа

Онлайн-оплата, автоматический расчёт доставки и личный кабинет относятся к последующему развитию. Дуги, многоуровневые потолки и производственный раскрой не включены в редактор первого этапа.

## Решения для согласования

Нужно утвердить нормы расчёта материалов, способ ввода размеров сложной комнаты, источник каталога и подготовленные макеты интерфейса. Полный перечень — в [вопросах для согласования](./questions.md).
