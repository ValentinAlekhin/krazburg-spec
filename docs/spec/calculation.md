# 3. Расчёт материалов {#p-3}

Сайт показывает предварительную стоимость. Нормы расхода, запасы, коэффициенты и правила округления будут уточнены после изучения текущего сайта и проверки примеров расчётов.

## 3.1. Основа расчёта {#p-3-1}

### 3.1.1. Размеры и параметры помещения {#p-3-1-1}

Количество материалов определяется по размерам помещения и выбранным параметрам потолка. Набор необходимых измерений будет уточнён по текущему конструктору.

### 3.1.2. Нормы расхода и округление {#p-3-1-2}

Для материалов должны быть определены нормы расхода, запас, единицы продажи и правила округления. Ожидаемые количества проверяются на эталонных примерах.

### 3.1.3. Цены {#p-3-1-3}

При расчёте используются цены товаров, заданные сотрудниками в админке Strapi.

### 3.1.4. Совместимость и состав {#p-3-1-4}

Комплект проверяется по правилам совместимости и наличию обязательных позиций. Конкретные сочетания и обязательные материалы будут уточнены по ассортименту и текущему сайту.

## 3.2. Проверка и сохранение {#p-3-2}

### 3.2.1. Серверная проверка {#p-3-2-1}

Strapi проверяет расчёт на сервере и сохраняет его вместе с заявкой.

### 3.2.2. Проверка менеджером {#p-3-2-2}

Покупатель получает предварительную смету. Перед изготовлением менеджер проверяет размеры и комплект.

### 3.2.3. Изменение правил {#p-3-2-3}

Сотрудники меняют предусмотренные параметры правил через админку. Новый алгоритм расчёта добавляет разработчик.
