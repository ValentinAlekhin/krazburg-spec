# Расчёт материалов

::: warning Требует согласования
Сайт показывает предварительную стоимость. Нормы расхода, запасы, коэффициенты и правила округления нужно утвердить.
:::

## Параметры расчёта

| Что нужно утвердить | Что определяет |
| --- | --- |
| Необходимые размеры помещения | Какие измерения вводит покупатель |
| Нормы расхода и запас | Количество каждого материала в комплекте |
| Округление и единицы продажи | Покупаемое количество штучных и погонных материалов |
| Совместимость и обязательные позиции | Полноту и допустимость выбранного комплекта |
| Цены и коэффициенты | Предварительную стоимость |
| Эталонные примеры | Ожидаемый состав, количества и стоимость для проверки |

## Ответственность системы

Strapi выполняет серверную проверку расчёта и сохраняет его вместе с заявкой. Покупатель получает предварительную смету; менеджер проверяет размеры и комплект перед изготовлением.

Сотрудники меняют предусмотренные параметры правил. Новый алгоритм добавляет разработчик.
