# Приёмка

Перед запуском проверяются расчёт комплектов, сценарии покупателя, обработка заявок и восстановление системы. Ожидаемые результаты расчётов и числовые показатели скорости ещё нужно согласовать.

| Сценарий | Ожидаемый результат |
| --- | --- |
| Расчёт типовой и сложной комнаты | Состав, количества и стоимость совпадают с утверждёнными эталонными примерами |
| Несколько комнат в проекте | У каждой комнаты свои параметры и комплект; заявка объединяет комнаты и общую смету |
| Замена комплектующей | Комплект проверяется по утверждённым правилам совместимости |
| Возврат к черновику в этом браузере | Покупатель продолжает незавершённый расчёт без регистрации |
| Отправка заявки | Расчёт и контактные данные доступны менеджеру в админке; ему отправлено уведомление по email |
| Работа с телефона | Покупатель проходит расчёт и отправляет заявку по утверждённому мобильному макету |
| Восстановление из копии | Данные и файлы восстанавливаются в согласованные сроки с допустимой потерей данных |

Для проверки скорости нужно утвердить допустимое время открытия страницы и пересчёта комплекта, устройства покупателя и ожидаемую нагрузку.
