# Каталог и готовые комплекты

Каталог содержит товары и готовые комплекты. Покупатель может использовать готовый комплект как основу и менять его состав по правилам совместимости.

## Ассортимент и правила продажи

| Что нужно согласовать | Необходимые сведения |
| --- | --- |
| Категории и карточка товара | Действующий ассортимент, обязательные характеристики и изображения |
| Единицы продажи, цены, доступность | Правила заказчика |
| Совместимость | Матрица допустимых сочетаний |
| Готовые комплекты | Состав, обязательные позиции и разрешённые замены |
| Обновление каталога | Источник товаров и цен, порядок изменения доступности |

Цена и состав готового комплекта должны рассматриваться совместно с [правилами расчёта](./calculation.md).
