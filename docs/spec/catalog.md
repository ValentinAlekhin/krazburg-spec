# 4. Каталог и готовые комплекты {#p-4}

Каталог содержит товары и готовые комплекты для самостоятельного монтажа натяжного потолка.

## 4.1. Товары и цены {#p-4-1}

### 4.1.1. Источник каталога {#p-4-1-1}

Товары, их характеристики и изображения добавляются и изменяются через админку Strapi. Сайт получает каталог из Strapi.

### 4.1.2. Управление ценами {#p-4-1-2}

Сотрудники задают и обновляют цены товаров через админку Strapi. Эти цены используются в каталоге и расчёте комплекта.

## 4.2. Готовые комплекты {#p-4-2}

### 4.2.1. Начало с готового решения {#p-4-2-1}

Покупатель может использовать готовый комплект как основу своего проекта.

### 4.2.2. Изменение состава {#p-4-2-2}

Покупатель меняет состав готового комплекта по правилам совместимости. Цена и состав рассчитываются совместно с [правилами расчёта из раздела 3](./calculation.md#p-3).

## 4.3. Детали ассортимента {#p-4-3}

Категории, обязательные характеристики, единицы продажи, правила доступности, состав готовых комплектов и разрешённые замены будут уточнены после изучения действующего ассортимента и текущего сайта.
