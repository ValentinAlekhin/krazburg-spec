# 2. Админка Strapi {#p-2}

Сотрудники заказчика управляют содержанием сайта, товарами, ценами и опциями через Strapi без изменения программного кода. Сайт использует опубликованные данные админки.

## 2.1. Что можно редактировать {#p-2-1}

| Раздел | Данные |
| --- | --- |
| Страницы и пояснения | Заголовки, тексты, инструкции, FAQ, подписи полей и кнопок, подсказки конструктора |
| Виды потолков | Способы монтажа, материалы, фактуры, цвета, описания, изображения и допустимые сочетания |
| Товары | Группы и позиции комплектующих, названия, описания, характеристики, изображения, цены, единицы продажи и упаковки |
| Настройки расчёта | Доступные ширины, тарифы, ограничения размеров, минимальные суммы, усадка, округление, параметры посылок, доставка и сборы |
| Отзывы и медиа | Тексты отзывов, фотографии, видео, подписи и ссылки на источник |
| Навигация и контакты | Меню, шапка, подвал, контакты, ссылки поддержки и кнопок |

## 2.2. Изменение и публикация {#p-2-2}

Сотрудник добавляет и изменяет записи, задаёт порядок элементов, публикует и скрывает их. Изображения и видео загружаются и заменяются через админку. Перед публикацией проверяются обязательные поля и связи между вариантами.

Новый вид потолка или опция добавляется в рамках существующих правил расчёта. Скрытые позиции не предлагаются для нового выбора. Изменение каталога не меняет сохранённые состав, наименования, цены и статусы ранее оформленных расчётов и заказов.

## 2.3. Доступ сотрудников {#p-2-3}

Вход в админку защищён учётными записями. Права на изменение контента, товаров и настроек выдаются сотрудникам по согласованным обязанностям.
