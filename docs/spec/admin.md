# Работа сотрудников

Основой административной части служит Strapi. Конструктор и приём заявок требуют собственных серверных модулей проекта.

## Что доступно без разработчика

| Сотрудник меняет | Граница возможности |
| --- | --- |
| Товары и характеристики | В рамках согласованной структуры каталога |
| Цены и доступность | По утверждённым единицам продажи |
| Готовые комплекты | В пределах правил состава |
| Совместимость | Через предусмотренные настройки |
| Коэффициенты и параметры | Только в заранее реализованных алгоритмах |
| Заявки | Через согласованные статусы и комментарии |

Новые алгоритмы расчёта добавляет разработчик. Универсальный визуальный редактор формул в первый этап не входит.

## Требует согласования

Роли сотрудников, обязательные поля, предварительный просмотр изменений и правила публикации. Конкретные права доступа будут согласованы отдельно.
