# Пакеты и окружение

Эта страница объясняет выбор инструментов для ТЗ. Версии проверены 2 ноября 2026 года и закреплены в `package-lock.json`.

## Что установлено

| Инструмент | Версия | Для чего нужен |
| --- | --- | --- |
| VitePress | 1.6.4 | Превращает Markdown в сайт с меню, поиском и оглавлением |
| Vue | 3.5.44 | Основа темы и будущих небольших интерактивных макетов |
| Mermaid | 12.2.0 | Строит диаграммы по текстовому описанию |
| vitepress-mermaid-renderer | 1.2.3 | Показывает диаграммы с масштабированием и полноэкранным просмотром |
| Playwright | 1.64.1 | Скачивает публичную часть старого сайта и проверяет документацию в браузере |

Используем npm и Node.js 22.12 или новее: это минимальная версия для выбранного Mermaid. Для GitHub Actions выбрана Node.js 24. Nuxt и Strapi здесь не устанавливаются: это отдельные приложения будущего проекта, а данный репозиторий хранит документацию и инструменты исследования.

## Почему выбран этот Mermaid-пакет

[Предложенный renderer](https://github.com/sametcn99/vitepress-mermaid-renderer) поддерживает Mermaid 11 и 12, Vue 3, тёмную тему и перевод элементов управления. Он обрабатывает обычные блоки `mermaid` в Markdown. Это позволяет хранить исходники диаграмм рядом с требованиями.

Альтернатива — [vitepress-plugin-mermaid](https://github.com/emersonbottero/vitepress-plugin-mermaid). Для выбранного варианта дополнительный обработчик Mermaid не требуется; одновременно два решения не подключаем.

Версия VitePress 1.6.4 выбрана как стабильная. Документация основной ветки VitePress уже описывает возможности версии 2.0 alpha; переносить их в этот проект без проверки нельзя.

Для зависимости Vite внутри VitePress задано точечное переопределение на Vite 6.4.5. Оно убирает известные уязвимости старой цепочки Vite 5 / esbuild без перехода на предварительную версию VitePress. Совместимость проверяется сборкой и браузерной проверкой; при обновлении VitePress это переопределение нужно пересмотреть. После установки выбранного набора `npm audit` не сообщает об известных уязвимостях.

::: info Что проверяем отдельно
Renderer создаёт SVG после открытия страницы в браузере. Сам факт успешной сборки ещё не подтверждает отображение диаграмм. Браузерная проверка проверяет диаграммы, масштабирование, полный экран, поиск, переходы, смену темы и узкий экран.
:::

Mermaid подключается после монтирования страницы, со строгим режимом обработки разметки. Для интерфейса renderer используется русская локаль корневого раздела. Если потребуется новый тип диаграмм, сначала проверяем его на собранном сайте.

## Публикация

Сайт собирается в `docs/.vitepress/dist`. GitHub Actions запускает проверки и передаёт только эту папку в GitHub Pages. Снимки старого сайта из `research/` в публикацию не входят.

Для адреса `owner.github.io/repository/` нужен путь `/repository/`. Переменная `VITEPRESS_BASE` позволяет задать его при сборке. Workflow получает значение из настроек Pages; локально по умолчанию используется `/`. Ссылки на страницы сохраняют расширение `.html`, чтобы не зависеть от правил переадресации сервера.

Репозиторий проекта — [ValentinAlekhin/krazburg-spec](https://github.com/ValentinAlekhin/krazburg-spec). Workflow публикует ветку `main` через GitHub Actions. При переносе в другой репозиторий нужно включить **Settings → Pages → Source → GitHub Actions**; если основная ветка называется иначе, заменить её имя в workflow.

## Обновление зависимостей

Обновляем пакеты намеренно, с сохранением lock-файла. После обновления выполняем `npm test`, `npm run docs:build` и `npm run docs:check`. Изменения Mermaid дополнительно проверяем на страницах с диаграммами и по вложенному пути публикации.
